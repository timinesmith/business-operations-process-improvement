# Process Improvement Method

**Status:** Illustrative demonstration.

## 1. Define the problem in operational terms

Avoid labels such as "communication issue" until the failure point is observable. State where the work stops, how often it happens, and what it costs in time, rework, or customer impact.

## 2. Map the current state

Document the actual steps, handoffs, systems, approvals, and waiting time — not only the intended process.

## 3. Measure the baseline

Select a small KPI set: volume, cycle time, first-pass quality, on-time completion, rework, and open blockers.

## 4. Identify the constraint

Look for the step that limits the whole workflow: missing information, a single approver, inventory timing, unclear specifications, or capacity concentration.

## 5. Test one change

Use a checklist, standard intake form, earlier procurement trigger, visual queue, or second reviewer. Define the test period and success measure before starting.

## 6. Standardize or revise

If the test improves the KPI without creating a new bottleneck, update the SOP and train the team. If not, record the result and test another intervention.
